# 예배 중 빠른 실행(큐) 방향

예배 도중 인도자·특정 악기·전체에게 보내는 빠른 실행을 정리한 문서입니다. 목업 3안(A 받는 사람 먼저, B 펄스 링 다이얼, C 무대 배치도 + 전체 공지)을 비교한 뒤 **A안 구조**로 진행하기로 했습니다.

- 목업 캔버스: [빠른 큐 목업 3안](https://claude.ai/artifact/FtuBnWgRH7LDoSFKv2WQaF) (A안 두 화면이 수정본)
- 예배 시작 화면 목업: [예배 시작 화면 목업](https://claude.ai/artifact/2Ao13uVEPdsnzwYgx5sMqh)

## 원칙

- **확인 받을 시간이 없다.** 목적은 보내는 것 하나다. 보내기 전 확인, 받는 쪽의 "확인했어요"·응답 버튼, 읽음 집계는 두지 않는다.
- **빠른 실행은 미리 등록해 둔 것만 쓴다.** 예배 중 직접 입력은 기본 흐름에서 뺀다. 등록·수정은 "등록 편집"에서 예배 전에 한다.
- **받는 쪽은 바로 토스트로 뜬다.** 화면을 가리지 않고, 저절로 사라진다.

## 보내는 화면 (A안 수정)

- 진행 화면 아래에 "빠른 실행" 영역이 항상 열려 있다(여는 동작 없음).
- 위쪽 탭에서 받는 사람을 고른다: 전체 · 악기 · 드럼 · 건반 · 기타 · 베이스 · 싱어 · 음향 · 미디어. 내 역할이 인도자가 아니면 인도자 탭이 맨 앞에 온다.
- 탭을 고르면 그 대상에 등록된 빠른 실행이 2열 큰 버튼(6개)으로 보인다.
- 버튼을 한 번 누르면 즉시 전송된다. 누른 버튼이 잠깐 큐 종류 색으로 바뀌고, 위에 짧은 토스트("드럼 · 느려요 보냈어요")가 약 1.6초 뜬다.
- 미접속 대상도 막지 않고 보낸다. 토스트에 "지금 접속한 기기는 없어요"만 표시한다.

## 받는 화면

- 받은 큐는 화면 위쪽에 버튼 없는 토스트로 뜨고 5.5초 뒤 자동으로 사라진다. 아래 진행 화면은 그대로 쓸 수 있다.
- 최신 1개는 크게(큐 이름·보낸 사람 → 대상·한 줄 설명), 이전 큐는 작게 표시하며 최대 3개까지 쌓인다.
- 남은 시간은 아래쪽 막대로 보이고, 토스트를 탭하면 바로 닫힌다.
- 큐 종류 색: 흐름 하늘색, 템포 앰버, 음향 로즈, 반주 세이지, 미디어 바이올렛.

## 현재 코드와의 차이 (구현 시 할 일)

- `components/session/SessionCueToasts.tsx`: "확인" 버튼과 닫기 버튼을 빼고, 토스트 전체를 탭하면 닫히게 바꾼다. 최신 토스트를 크게, 나머지를 작게 표시한다. 수명 5.5초와 최대 3개는 지금 값 그대로다.
- 받는 사람 탭: 지금 수신 역할은 인도자·악기·미디어 세 가지뿐이다. 드럼·건반 같은 악기별 대상을 쓰려면 각 기기가 자기 악기를 고르는 설정과, 그 값으로 거르는 수신 규칙이 필요하다.
- 등록된 빠른 실행: 기존 `quickFeedbackPresets`(라벨·메시지·대상·종류)를 받는 사람 탭별로 묶어 보여 준다. 프리셋의 `target` 값이 탭 구분 기준이 된다.
- 진행 화면(BPM 펄스 뷰)의 기존 "즉시 큐" 패널을 이 빠른 실행 영역으로 대체할지는 구현 전에 정한다.

## 이번에 하지 않는 것

- B안의 질문형 큐와 답하기, C안의 무대 배치도·전체 공지 화면 덮기·파트별 지시·확인 집계는 보류한다.
