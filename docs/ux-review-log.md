# UI/UX 정기 평가 기록

90분마다 같은 기준으로 화면을 점검하고, 우선순위가 높은 항목부터 프론트엔드에 반영합니다.

**측정 방법:** 개발 전용 로그인 서버(`scripts/e2e-server.mjs`)에서 Pixel 7(412px)·데스크톱(1440px) 전체 화면 캡처, axe(WCAG 2.2 AA) 검사, 24×24px 미만 터치 영역(WCAG 2.5.8) 탐지, 가로 넘침 측정.
**대상 화면:** `/dashboard`, `/dashboard/songs`, `/dashboard/planning`, `/dashboard/team`, `/guide`, `/login`, `/care`, `/serve`, `/community`

## 2회차 · 2026-11-05 — 디자인 · 사용성 · 핵심 기능

**측정 방법 추가:** 휴대폰(Pixel 7) 두 기기로 핵심 흐름을 끝까지 실제 조작 — 인도자: 이름 → 팀 만들기 → 초대 링크 → 역할 지정 → 일정 만들기 → 역할·담당자 추가 → 곡 3개 등록 → 콘티 저장 → 예배 시작 / 팀원: 초대 링크 → 로그인 → 참여 → 배치 확인 → 참석 응답 → 예배 입장. 단계마다 화면 캡처.

| 핵심 흐름 | 결과 | 비고 |
| --- | --- | --- |
| 팀 만들기 · 초대 | 통과 · 4화면 | 온보딩 2단계가 짧고 명확. 초대 링크 즉시 생성 |
| 초대 수락 | 통과 · 3탭 | 유효기간 · 팀 이름이 먼저 보여 신뢰감 있음 |
| 일정 · 배치 | 통과 · 폼 2개 | 저장 피드백 명확. 배치 직후 팀원 홈 ‘팀 배치 1/1’ 즉시 반영 |
| **팀원 참석 응답** | **통과했지만 찾기 어려움** | 응답 버튼이 카드 맨 아래(상세 → 빈 ‘안내 사항’ → 빈 ‘알림 기록’ → 배정 → 내 섬김) 5번째 구역. 떠 있는 ‘새 알림’ 버튼이 그 줄(.ics)을 가림 |
| 곡 · 콘티 | 통과 · 곡당 폼 1회, 곡 고르기 1탭 | 고른 곡 칩이 ‘✓ 추가됨’으로 바뀌어 상태가 분명 |
| 예배 시작 · 입장 | 통과 | 팀원 기기가 자동으로 따라 들어옴. JS 오류 0 |

전체 흐름 소요(자동 조작) 33초, 페이지 오류 0.

| 기준 | 점수(5) | 근거 |
| --- | --- | --- |
| 핵심 기능 완결성 | 4.5 | 초대 → 응답 → 콘티 → 실시간 예배까지 두 기기에서 끊김 없음 |
| 사용성 | 3 → 4 | 팀원의 유일한 필수 동작(참석 응답)이 묻혀 있었음 → 카드 맨 위로 |
| 디자인 위계 | 3.5 | 홈 타일 날짜 기준이 서로 다름: 콘티 · 팀 배치 타일은 다음 예배(11/12), 일정 타일은 이번 주(11/2–8)만 보고 ‘일정이 없어요’ |
| 일관성 | 3.5 | 떠 있는 ‘새 알림’이 머리 영역 종 아이콘 · 일정 화면 ‘내 알림’과 같은 내용을 세 번째로 반복하며 본문을 가림 |

**반영**
- 일정 카드: 내가 배치됐고 아직 응답하지 않았으면 카드 맨 위에 ‘○○ 자리에 배치됐어요 · 참석 확정 / 못 가요(사유 칩 1탭)’ — 응답하면 사라짐
- 팀원에게는 비어 있는 ‘안내 사항’ · ‘알림 기록’ 구역을 숨겨 배정 · 참석이 위로
- 일정·요청 화면에서는 떠 있는 ‘새 알림’ 버튼을 숨김(같은 알림함이 본문에 있음)
- e2e(team-journey)에 응답 영역 노출 · 응답 후 사라짐 검사 추가

### 반영
- **예배 접속 · 진행 누락 수정:** 실시간 소식이 처음 연결되면 예배 상태를 한 번 다시 읽어, 그 사이의 입장 · 곡 이동 · 큐를 맞춤 (`components/live/useLiveSession.ts`)
- **일정 → 콘티 링크 수정:** 앱 안 이동으로 콘티 · 악보 화면에 들어오면 이전 화면 주소를 읽지 않고 새 주소의 탭 · 콘티를 엶 — 홈 ‘콘티 열기’, 팀 소식 종도 같은 경로 (`components/conti/ContiWorkspace.tsx`)
- **D-day 통일:** 일정 카드도 한국 날짜 기준 달력 일수로 셈 → 홈 · 콘티와 같은 D-day, ‘오늘’ · ‘내일’ 정확 (`components/planning/SchedulePanel.tsx`)
- e2e: 팀원이 일정 카드에서 ‘콘티 · 악보 보기’를 누르면 ‘콘티’ 탭 · 그 콘티 제목이 보이는지 검사 추가
