# 콘티 마감 알림 · 인도자 콘티 요청 지침

> **상태:** 구현됨 (서버 예약 알림 · 콘티·악보 화면)
> **화면:** 콘티·악보 → ‘이번 주’의 **콘티 마감** 카드. 디자인 참고용 목업은 `/dashboard/songs/deadline`에 그대로 둡니다.
> **모바일 디자인 기준:** `claude/relaxed-tesla-upror8` 브랜치의 콘티·악보 디자인(`components/conti`)

## 1. 확정 결정

| 항목 | 결정 |
| --- | --- |
| 콘티 마감 | 예배 전 **화요일까지** (23:59) |
| 곡 제목만 먼저 올린 경우 | **초안**: 팀에 알림은 가지만 마감은 아직. **확정**은 끝까지 다 올렸을 때 |
| 마감 전 요청 | **허용** |
| 이름 숨김 요청 | **허용** |
| 앱을 닫았을 때 알림 | **지원** (Web Push) |

## 2. 콘티 마감

- 기본 마감: 예배일 이전의 가장 가까운 **화요일 23:59** (한국 시간)
  - 주일 11/1 → 10/27(화) 23:59
  - 수요예배 10/28 → 10/27(화) 23:59 (하루 전)
  - 예배가 화요일이면 1주 전 화요일
- 마감 대상은 **예배 일정**(종류 ‘예배’)과 그날 연결된 콘티입니다. 일정 없이 만든 콘티는 콘티 날짜로 따로 계산합니다.
- 팀 관리자가 기본 규칙을 바꿀 수 있고, 인도자 · 관리자는 예배마다 마감을 따로 정할 수 있습니다.
- **콘티 상태**
  - 작성 중: 알림 없음
  - **초안 공유**(곡 제목만 먼저): 그 예배에 배치된 팀원에게 `콘티 초안이 올라왔어요`. 마감은 아직 지키지 않은 상태입니다.
  - **확정**(끝까지 다 올림): 배치된 팀원 + 요청한 팀원에게 `콘티가 확정됐어요`. 마감을 지킨 상태이며 열린 요청은 자동으로 완료됩니다.
- 콘티 담당은 이름으로 적혀 있어, 같은 이름의 팀원이 한 명이면 그 사람을 담당 인도자로 봅니다. 없으면 예배의 인도 자리, 그것도 없으면 인도자 · 관리자 전체입니다.

## 3. 알림 일정 (서버가 1분마다 확인)

| 시각 (기본 설정) | 받는 사람 | 내용 |
| --- | --- | --- |
| 월 21:00 | 담당 인도자 | 콘티 마감 하루 전이에요 |
| 화 20:59 | 담당 인도자 | 콘티 마감 3시간 전이에요 |
| 화 23:59 → **수 07:00 발송** | 담당 인도자(긴급) | 콘티 마감이 지났어요 |
| 〃 | 배치된 팀원 | 아직 콘티가 올라오지 않았어요 (초안만 있으면 ‘콘티 초안만 올라와 있어요’) |
| 마감 + 12시간 | 팀 관리자(긴급) | 콘티 미확정 12시간이 지났어요 |

- 확정된 예배, 이미 지난 예배, 인도자가 알려 준 **예정 시간까지**는 보내지 않습니다.
- 늦게 켜져 지난 단계의 알림은 건너뜁니다(하루 전 알림을 3시간 전 단계 이후에 보내지 않음).
- 보낸 알림은 기록해 다시 보내지 않습니다. 예배 마감을 바꾸면 새 마감 기준으로 다시 알립니다.
- **밤 시간(23:00–07:00)**: 예약 알림은 07:00에 보냅니다. 밤에 들어온 콘티 요청 · 예정 시간 알림은 앱 안 목록에는 바로 보이고, 기기 · 푸시 알림만 07:00에 갑니다.

## 4. 팀원 요청(독촉)

- **보낼 수 있는 사람:** 팀원 누구나 (본인이 담당 인도자인 예배 제외)
- **마감 전:** 요청할 수 있고 버튼은 보통 모양입니다. 경고는 띄우지 않습니다.
- **마감 후:** 마감 카드가 주황으로 바뀌고 요청 버튼이 강조됩니다.
- **보내는 말:** 정해진 문구 4개 중 하나 + 덧붙일 말(200자)
- **재요청 제한:** 같은 팀원은 같은 예배 콘티를 3시간에 한 번 요청할 수 있습니다. 보낸 요청은 취소할 수 있습니다.
- **인도자 알림 묶음:** 같은 3시간 안의 요청은 알림 하나를 고쳐 씁니다. 예: `윤사랑님 외 2명이 콘티를 요청했어요`
- **예정 시간 답변:** 인도자가 ‘오늘 밤 안에 · 내일 오전까지 · 곡 제목부터 먼저(3시간)’ 중 고르면 요청한 사람에게 알리고, 그 시각까지 요청과 마감 알림을 멈춥니다.
- **자동 완료:** 콘티가 확정되면 그 예배의 열린 요청을 완료합니다.
- **저장:** 요청함의 `진행 확인 요청(reminder)`에 마감 대상 키를 붙여 저장합니다. 쓴 사람 · 받는 인도자 · 관리자는 요청함에서도 봅니다.

## 5. 이름 숨김

- 인도자와 관리자 모두에게 `팀원 1명`으로 보입니다.
- 서버는 재요청 제한과 취소를 위해 작성자를 저장하지만, 화면으로 내려보내는 데이터(`planningForViewer`)에서는 작성자를 지웁니다.
- 다른 팀원에게는 요청 내용 없이 **기다리는 인원**만 보입니다.

## 6. 앱을 닫았을 때 알림 (푸시)

- 마감 · 요청 알림도 다른 팀 소식과 같은 길로 보냅니다: 앱 안 팀 소식 · 기기 알림 · Web Push.
- 운영 서버에 `VAPID_PUBLIC_KEY` · `VAPID_PRIVATE_KEY`가 있어야 푸시가 갑니다(`.env.example` 참고).
  - Android 크롬 · 설치형 PWA: 바로 지원
  - iPhone: 홈 화면에 추가한 경우(iOS 16.4 이상)만
- 알림을 누르면 콘티·악보 ‘이번 주’로 갑니다.
- 카카오 알림톡과 Capacitor 앱의 FCM 푸시는 아직 없습니다.
