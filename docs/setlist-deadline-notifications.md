# 콘티 마감 알림 · 인도자 콘티 요청 지침

> **상태:** 정책 확정, 구현 전
> **목업:** `/dashboard/songs/deadline` (콘티·악보 → ‘콘티 마감 알림 목업 보기’)
> **모바일 디자인 기준:** `claude/relaxed-tesla-upror8` 브랜치의 콘티·악보 디자인(`components/conti`)

## 1. 확정 결정

| 항목 | 결정 |
| --- | --- |
| 콘티 마감 | 예배 전 **화요일까지** |
| 마감 전 요청 | **허용** |
| 이름 숨김 요청 | **허용** |
| 앱을 닫았을 때 알림 | **지원** (푸시) |

## 2. 콘티 마감

- 기본 마감: 예배일 이전의 가장 가까운 **화요일 23:59** (한국 시간)
  - 주일 10/18 → 10/13(화) 23:59
  - 수요예배 10/21 → 10/20(화) 23:59
  - 예배가 화요일이면 1주 전 화요일
- 인도자·관리자는 일정별로 마감을 바꿀 수 있습니다.
- **마감 충족 기준:** 콘티를 확정(공유)하거나 곡 제목만 먼저 공유한 시점입니다. ‘작성 중’ 상태는 충족이 아닙니다.
- 마감 후에 등록하면 `마감 N시간 후 등록`으로 기록만 남깁니다. 불이익은 없습니다.

## 3. 알림 일정

| 시각 | 받는 사람 | 내용 |
| --- | --- | --- |
| 월 21:00 | 인도자 | 마감 하루 전 |
| 화 21:00 | 인도자 | 마감 3시간 전 |
| 화 23:59 → **수 07:00 발송** | 인도자(긴급) · 배정 팀원 | 마감 지남 (밤 시간이라 아침에 발송) |
| 수 12:00 | 팀 관리자 | 마감 후 12시간 동안 콘티 미등록 |
| 콘티 등록 즉시 | 배정 팀원 | 콘티가 올라왔어요 |

- **밤 시간(23:00–07:00):** 모든 알림을 모아 두었다가 07:00에 보냅니다.

## 4. 팀원 요청(독촉)

- **보낼 수 있는 사람:** 해당 일정에 배정된 팀원
- **마감 전:** 요청할 수 있고, 버튼은 보통 모양으로 둡니다. 경고 배너는 띄우지 않습니다.
- **마감 후:** 경고 배너를 띄우고 요청 버튼을 강조합니다.
- **보내는 말:** 정해진 문구 4개 중 하나를 고르고, 덧붙일 말을 200자까지 쓸 수 있습니다.
- **재요청 제한:** 같은 팀원은 같은 콘티에 3시간에 1번만 요청할 수 있습니다.
- **인도자 알림 묶음:** 3시간 단위로 묶어 보냅니다. 예: `박건반 외 2명이 콘티를 요청했어요`
- **예정 시간 답변:** 인도자가 예정 시간을 답하면 기다리는 팀원 모두에게 공유합니다.
  - 그 시각까지는 요청 버튼과 마감 알림을 멈춥니다.
- **자동 완료:** 콘티가 등록되면 열린 요청을 자동으로 완료 처리합니다.
- **저장 방식:** 기존 요청함의 `진행 확인 요청(reminder)`으로 저장해 요청함에서도 보이게 합니다.

## 5. 이름 숨김

- 인도자와 관리자 모두에게 `팀원 1명`으로 표시합니다.
- 서버는 재요청 제한과 취소 처리를 위해 작성자를 저장합니다.
  - 다른 사람에게 내려보내는 데이터(`planningForViewer`)에서는 작성자를 제거합니다.
- 보낸 사람 본인의 화면에는 `이름 숨김으로 보냄`을 표시합니다.

## 6. 앱을 닫았을 때 알림 (푸시)

- **1차 – 웹 푸시:** 기존 PWA 서비스 워커(`public/sw.js`)를 확장하고 VAPID 키를 씁니다.
  - Android 크롬과 설치형 PWA에서 동작합니다.
  - iOS는 홈 화면에 추가한 경우(iOS 16.4 이상)만 됩니다.
- **Android 앱(Capacitor):** FCM 푸시를 따로 연결합니다.
- **카카오 알림톡:** 비즈니스 채널, 템플릿 심사, 건당 비용이 필요해 2차로 검토합니다.
- **알림 권한 요청 시점:** 처음 요청을 보낸 직후, 또는 인도자가 처음 로그인했을 때 묻습니다.
- **예약 발송:** 지금은 누군가 앱을 열어야 상태가 갱신됩니다.
  - 단일 서버에서 1분마다 마감·알림 시각을 검사해 보내는 작업을 추가합니다.
  - 같은 알림이 두 번 가지 않도록 발송 기록을 남깁니다.
- 앱 안 알림(내 알림·배지·배너)은 그대로 두고, 푸시는 추가 채널로 붙입니다.

| --- | --- |
| 팀 기본 마감 규칙 변경 | 팀 관리자 |

| 예정 시간 답변 | 요청을 받은 인도자 |

## 8. 화면 위치 (새 디자인 기준)

목업은 결정 1~4를 모두 반영했습니다. 실제 구현 시 콘티·악보 화면의 아래 위치에 붙입니다.

| 기능 | 위치 |
| --- | --- |
| 마감 상태 카드 · 요청 보내기 | ‘이번 주’ 콘티 카드 (마감 상태에 따라 카드 색과 문구가 바뀜) |
| 기다리는 팀원 · 예정 시간 답변 | 인도자의 ‘이번 주’와 ‘요청’ |
| 마감·요청 알림 | ‘팀 소식’ (새 알림 종류: 마감 알림, 콘티 요청, 예정 시간) |
| 마감 설정 | 팀 관리자 설정 |

## 9. 가정 (다르면 수정)

- 화요일 마감 시각은 시간이 따로 정해지지 않아 **23:59**로 정했습니다.
- 주중 예배에도 화요일 기준을 적용합니다. 수요예배는 마감이 하루 전이 됩니다.
